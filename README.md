# WolfGame

Projeto Unreal Engine. Abra o arquivo .uproject com a versao indicada em EngineAssociation.

## Recuperar o projeto

Instale Git e Git LFS e execute:

    git lfs install
    git clone https://github.com/OtavioBitencourt/WolfGame.git
    cd WolfGame
    git lfs pull

Caches (Saved, Intermediate, DerivedDataCache), binarios da raiz e configuracoes locais sensiveis nao sao versionados. Binarios de plugins sao preservados. Tokens Android devem ser configurados localmente, se necessarios. O ZIP antigo TheLostPirateBKP.zip nao integra este backup dos arquivos atuais.

Os assets e plugins de terceiros continuam sujeitos as respectivas licencas; este repositorio nao concede uma nova licenca sobre eles.
